Install to Get Started

Your Admin has invited you to the OKV Payroll & HR system. Install this app to your device, then log in with the username and password your Admin gave you.

Android (Chrome, Edge, Samsung Internet)

One tap in most cases.
  1. Tap the gold Install Now button above.
  2. Confirm by tapping Install in the popup that appears.
  3. The app opens automatically and its icon is added to your Home Screen — launch it from there anytime. You'll need internet to log in the first time; after that, it keeps working offline and syncs when you're back online.
If nothing happens when you tap Install Now, open your browser's ⋮ menu and choose "Install app" or "Add to Home screen".

iPhone / iPad (Safari)

iOS requires Safari — this must be added manually, Apple doesn't allow one-tap install.
  1. Open this page in Safari (not Chrome or another browser — iOS only allows installing from Safari).
  2. Tap the Share icon in the toolbar (bottom of screen on iPhone, top on iPad).
  3. Scroll down and tap "Add to Home Screen."
  4. Tap Add in the top-right corner.
  5. The app icon appears on your Home Screen — open it from there, then log in with the details your Admin gave you.
Opened this in Chrome or another app on iPhone? Copy the link into Safari first, since only Safari can add it to your Home Screen.

Windows / Chrome / Edge

Installs as a standalone desktop app.
  1. Click the gold Install Now button above, then click Install in the popup.
  2. If the button doesn't respond, look for an install icon at the right edge of the address bar and click it.
  3. The app opens in its own window and adds a shortcut to your Start Menu / Desktop.
Firefox on desktop doesn't support app installs — use Chrome or Edge, or continue in the browser without installing.

Mac (Safari)

macOS Sonoma (14) and newer.
  1. Open this page in Safari.
  2. From the menu bar choose File → Add to Dock… (or tap the Share icon and choose "Add to Dock").
  3. Confirm the name and click Add.
  4. The app opens in its own window and stays in your Dock — launch it anytime and log in with the details your Admin gave you.
On an older macOS without "Add to Dock," use Chrome or Edge on Mac instead — the gold Install Now button will work there.
