Roles Reference
    Full Backup

    A full backup downloads everything — employees, staff bio-data, payroll history, leave records, loan records, and your organization's settings — in one file to your device. Keep it somewhere safe (email it to yourself, save to Google Drive, etc.).

    Restore From Backup
    This replaces your current data. Restoring a backup overwrites everything currently in the system with what's in the file — there's no undo. Only restore a backup you trust, and consider downloading a fresh backup of your current data first (above) in case you need to go back.
    How Backups Work
    • Your data already lives safely in your organization's own private online spreadsheet — a backup is an extra personal copy, not the only copy.
    • JSON backup is the complete, exact copy — best for restoring later, since it captures every field precisely.
    • CSV backup gives you one spreadsheet-friendly file per data type (Employees, BioData, Payroll, Leave, Loans) — best for opening in Excel or Google Sheets.
    • We recommend downloading a fresh backup monthly, and always before a large bulk import or edit.
    • Restoring only affects data on this device until it next syncs — if you're offline when you restore, review the result before reconnecting.
    Need to move just one type of data (e.g. only Employees)? Use the Import CSV / Export CSV buttons on that section's own page instead — they're more precise for single-collection updates.
